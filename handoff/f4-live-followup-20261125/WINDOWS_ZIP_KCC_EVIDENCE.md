# F4 ショクワンダー KCC往復（Windows、2026-11-25）

既存の全地形ローカル研究ラウンドの隔離モード。Windows正本の `PlayerController.ts` と `UndertowF3PlayablePreviewApp.ts` を更新した。正式フック適格性と得点はHOLD。

## 起動と操作

既存ランチャーで `http://127.0.0.1:4176/` を開く。同一タブで開発者コンソールから以下を設定してリロードする。開始前にアークブラスターを選択する。Wで開始地点から約10 m進み、接地してGを押す。

```js
sessionStorage.setItem('t21F4SpecialProbe', 'physical')
sessionStorage.setItem('t21F4ZipKccResearch', 'wall-return')
location.reload()
```

Gは確認地点の周辺から既存壁に向けた実レイを照合する。現位置の支持と往復カプセル掃引が通れば、通常移動と同じRapier KCCに固定tickごとの移動要求を渡す。壁で実KCC接触を記録した時点で帰還し、発射時に確認した支持面へ実接地すると完了する。阻害やタイムアウトでその位置に停止する。状態は `window.__t21F3.f4ZipKccResearch()` で読める。

## 実測

- Chrome CDPのクリック、W、Gで実行。前回約16.625 mで観測した壁候補を、今回の発射地点から16.062 mの実レイで捉えた。実KCC接触、帰還、接地を144tick（2.40秒）で記録。移動量33.028 m、最大実移動0.234 m/tick未満、帰還位置の差は約0.10 mm。ブラウザ例外0件。
- CPU戦闘は隔離フラグなしの別セッションで観測。WASDと左クリック3回を入力。tick2774までに敵CPU弾33発、対CPU接触3件、現在位置照準1回、予測照準5回。全体の実CPU HP減少カウンターは0から4。人間の命中数は分離できていない。局所ゴールは候補採用0件。中央手前の歩行を遮った実ステージ壁をKCCで確認し、横移動でも別の物理接触が発生した。CPU側の修正根拠は得られなかった。
- TypeScript型検査、Viteビルド成功。既存の正式QA、ステージ資料検索、180秒検証の再実行は行っていない。
