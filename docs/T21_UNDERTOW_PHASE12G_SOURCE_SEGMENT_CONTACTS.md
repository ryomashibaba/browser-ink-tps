## Why

The 16 Phase12F original FloorLine02 boundary edges consisted of zero original-vertex-ID welded static neighbor edges, twelve matching-XYZ non-welded endpoint seams, and four only-proximate edges: source minfaces #60006 and #61728, edge indices 1 and 2 on each. The four midpoint-to-original-triangle distances had near-zero results, but a midpoint distance is not a proof of an actual finite segment crossing/overlapping another triangle.

Phase12G reads the **43,263,289-byte SHA256-pinned original Temple01 OBJ**, verifies the fixed Phase12F adjacency JSON exactly, and scans every active original triangle. For each unresolved edge, it robustly computes finite 3D segment-triangle point-plane intersections (including hit source segment parameter, source XYZ and plane-distance certificate), coplanar segment/triangle clipping intervals (including contact length), or true 3D segment-to-triangle minimum distance using segment-to-segment and point-to-triangle nearest points. The contact is separated into `SOURCE_POINT_PLANE_INTERSECTION`, `COPLANAR_SOURCE_SEGMENT_OVERLAP`, `COPLANAR_SOURCE_POINT_ONLY`, or `SOURCE_SEGMENT_NEAR_TRIANGLE_NO_INTERSECTION`, with original source face ID, material, object, OBJ vertex IDs and untrusted PntSet flag. Original internal faces of all four opted-in source components are excluded from false self-contact.

The report is a **source-only diagnostic**, not collision/nav/painting/path/water/ground truth: even a zero-distance actual 3D mesh intersection, coincident edge, or source-ID edge does not create a playable or physically closed floor. Actors/placement PntSet meshes are untrusted. No new triangles are created, no hard-XZ growth, renderer change or default source registration.
