# B497｜本物の拒否10経路の床ID・座標の特定と50経路の静的CPUカプセル診断

真正ChromiumのActions #43140584988（B450/B454）から再現できた60経路を使用し、B496でRay支持に失敗した10件は最初の失敗地点（投影Y・Rapier床Y・固体ID・座標）を全件保存する。Ray支持だけなら通過した50件は、同じ原作25 solidを持つ隔離Rapier世界で、**原作CPUと同サイズのカプセル**を最初の実Recast投影点に置き、以後の0.30m前後の投影点間変位を連続KCCで検査する。途中で実測足にリセットしない。

重要：これは実ゲームでCPUが選んだ操作ではなく、Recastの投影点をたどる**静的・反事実診断**。実7CPU＋Human同時の衝突、正式な中央横断、原作7.2.0の衝突フラグ、正式4v4・得点・ARTを認証するものではない。0.25mの通常ルート閾値、原作25/17/26/0、main、Draft PR #5、PRIVATE、正式QAを変更しない。

B497は投影後に大きい垂直ジャンプ（0.34m＝既存KCC autostep上限超え）をした経路も別カウントし、診断上の合格を正式経路認証に昇格させない。失敗時はそのまま証拠として扱い、閾値の緩和・架空の床・NavLink追加は禁止。

軽量CIトリガー：[p0-radar-build-only] [b497-path-kcc]。真のChromium/180秒試験は走らせない。

## B497追加速度制限診断（B497-S）
従来のKCCはRecast補間点を約0.3mごとに1物理tickで進めており、これは実CPUの最大4.4m/s、60Hzでの上限約0.0733m/tickより大きい。22/50件のKCC許容内・28/50件のクリップは、その**大きすぎる診断用移動要求**に対する結果であり実ゲームの適切な60Hz行動の証明ではない。

このため原作25固体の別の隔離Rapierカプセルへ、同じ50経路の各投影点間移動を**4.4m/s×1/60以下へ細分化**して再演。累積誤差・静的衝突・床支持を別々に報告する。経路の各点は真正B450/B454に基づくRecast再投影点だが、CPU AIが実際にその移動入力を生成したわけではない。**診断成功しても自然な移動経路の認証は不可**。
