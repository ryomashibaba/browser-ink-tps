# B383 — SOURCE CPUの武器射程に合う実際の交戦目標選択

**2026年10月31日 JST。** 継続方針: `dev/t21-f4e103w-qa-infra` のみ。原作25 Rapier solids / 17 PaintSurfaces / 26 NavLinks / 0 Scoreable は不変。正式4v4、得点と勝敗、本番承認はHOLD。

## 実コードで発見された実戦上の問題
`CpuAgentSystem.chooseCombatTarget` のB181版は、**32m以内の可視敵**から狙う相手を選び、SKIRMISHERは12m以内で可視の人間を優先する。その後 `updateCpuWeapon` で初めて各武器クラス固有の射程を確認する。そのため、マニューバー等の実射程9.8mに対し、11.8mの可視人間を選び、別の7.6mに真の見える敵がいても攻撃せず終わることがあった。8tickの視線キャッシュも実射程外への移動を考慮していなかった。

## 改修
- B181の既存「原作Rapier遮蔽あり／高さ差制限／生きた実Actor位置」の視線選択に、武器射程の**選択時上限**を追加。射程外敵は射線候補に含めず、隠れている射程内敵への命中を保証しない。
- CPU主武器の実射撃でだけ、既存 `cpuWeaponRangeMeters(weaponProfile(bot.weaponId))` と同じ値を渡す。どのCPUも新しい弾・ダメージ・速度・NPC・足元座標は得ない。射程内の実敵がいなければ従来通り、原作で既に許可された床塗りに移る。
- サブ・スペシャルは従来の独立した視線と距離判定を維持。B181の旧4引数呼び出しは32mのまま。未選択T20・original CPU pathには一切影響しない。
- 8tickキャッシュの敵が装備武器の射程外に出たら破棄し、既存のRapier遮蔽視線を再判定。再計算しても射程外は命中候補にならない。
- 既存B181 Unitテストを拡張し、優先人間より近い射程内の敵選択・物理壁遮蔽・範囲外キャッシュ破棄・不正数値・旧B181との互換を検査。新しいCIや研究専用ゲームモードを作らず、B75統合QAでビルド/テストを実施。
