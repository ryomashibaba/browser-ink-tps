# Phase12I independent gates — broad static original Temple01 3D structure

Original source survey extracts 9 symmetrically paired broad static original components (18 components / 350 original triangles) based on original shared vertex IDs, from 51 original object/material groups, 16,256 components and 70,396 active original faces. Candidate area is 3D triangle surface only, NOT gameplay floor. The CI independent TypeScript gate checks all 350 exact original source faces against the already registered 124 full source meshes and Phase12C8 + Phase12D4 optional source meshes, bitwise Float64 exact / 1e-7m near duplicates. Strictly verifies mirror geometry using full original vertex-ID coordinate multiset with 0.2mm tolerance (not material-name similarity). Hard-XZ 42-point frozen polygon validation samples seven points per triangle, intersects every original triangle edge with every outer boundary edge and flags boundary polygon vertices hidden inside any large original triangle. Thus large 300m² source quads cannot be admitted solely from a few inside samples.

The gate issues per-component decisions and a separate count of complete **both-sides eligible** pairs. No real source meshes are registered or rendered yet. Even a formally eligible mirrored full original source structure may be visually reviewed ONLY through a new separate opt-in diagnostic, never gameplay. No source viewport, default 124 meshes, frozen macro, production T20, T21 activationReady=false, physics/nav/paint/score change. PR #5 stays Draft/open/unmerged.
