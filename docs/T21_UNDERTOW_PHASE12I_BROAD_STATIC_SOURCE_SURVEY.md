Compared with small Phase12H metal/glass contact markers, this stage seeks larger original Stage Temple01 structure candidates with high 3D surface area, enough triangles to have meaningful geometry and 180° mirrored original connected components. Reads all 70,396 active faces from the SHA256-pinned original KiTrix 43,263,289-byte Temple01 OBJ, groups triangles by exact same original object+material and actual **shared original OBJ vertex IDs**, expressly excludes PntSet actor placement and StageSide. Computes area/XYZ bounds/height/unique original IDs, checks true source mirror multiset with 1e-4m quantization and matches one unique counterpart among all >=3m² source candidates. Excludes already-investigated Phase12C/12D components and previously held source components. A maximum of 18 mirror pairs / 1,800 source triangles is saved in a self-contained original-face+original XYZ JSON artifact, ranked by original 3D area; area is never playable XZ area. Each candidate awaits independent registered124+Phase12C8+Phase12D4 triangle overlap and exact frozen 42-point hard-XZ tests. Even a source-symmetric large component cannot be rendered unless it passes them.

The output is evidence-only and has no new mesh registration.
